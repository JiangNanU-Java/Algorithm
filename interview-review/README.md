## 📖 目录结构说明

每个主题目录下都包含以下标准结构：

- **topics/** - 核心知识点讲解
- **examples/** - 代码示例和实现

- **questions/** - 面试题整理和答案
- **resources/** - 参考资料、链接和工具

## 🎯 学习建议

### 📅 学习计划建议
1. **每日安排**: 2-3个小时，优先完成当前阶段内容
2. **周末复习**: 回顾本周学习内容，整理笔记
3. **阶段总结**: 每完成一个阶段，做一次综合复习

### 📝 学习方法
1. **循序渐进**: 严格按照序号顺序学习，不要跳跃
2. **理论实践结合**: 每个知识点都要有对应的代码实践
3. **面试导向**: 重点关注高频面试题和场景题
4. **及时复习**: 新学内容一周内复习2-3次

### 🎯 重点关注
- **算法题**: LeetCode中等难度以上，重点掌握动态规划、树图算法
- **场景题**: 多画架构图，多思考扩展性和容错性
- **系统设计**: 学会权衡各种方案，理解CAP理论等

## 🚀 快速开始

### 第一阶段 (1-3周)
1. **01-java-core**: 深入理解JVM、集合框架、并发编程
2. **02-database**: 掌握MySQL索引优化、事务隔离、Redis数据结构
3. **03-frameworks**: 精通Spring IOC/AOP、Spring Boot自动配置

### 第二阶段 (2-3周)
4. **04-os**: 进程线程、内存管理、IO模型
5. **05-network**: HTTP/TCP协议、三次握手、浏览器缓存
6. **06-design-patterns**: 单例、工厂、策略、观察者模式

### 第三阶段 (3-4周)
7. **07-theory**: 系统梳理各技术栈理论知识
8. **08-algorithms**: 每天1-2道LeetCode题，重点中等难度
9. **09-middleware**: Redis集群、消息队列、Elasticsearch

### 第四阶段 (2-3周)
10. **10-performance**: JVM调优、数据库优化、缓存策略
11. **11-security**: 加密算法、认证授权、常见安全漏洞

### 第五阶段 (3-4周)
12. **12-scenarios**: 秒杀系统、Feed流、短链接生成
13. **13-architecture**: 高可用架构、缓存架构、数据库架构
14. **14-microservices**: 服务拆分、注册发现、配置中心
15. **15-distributed**: 分布式锁、一致性算法、CAP理论

### 第六阶段 (2-3周)
16. **16-devops**: Docker、K8s、CI/CD流水线
17. **17-collaboration**: 项目管理、代码审查、团队协作

### 第七阶段 (持续更新)
18. **18-resume-projects**: 根据个人简历定制复习内容
19. **19-ai-applications**: AI集成、Prompt工程、模型调优
