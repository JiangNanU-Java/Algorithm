# 08-algorithms

这里是关于LeetCode算法题的详细学习资料和面试复习内容。

## 🎯 难度等级

⭐⭐⭐⭐ (较难)

## 💡 学习建议

建议时长：4-6周。重点：动态规划、树图算法、排序搜索。实践：每天1-2道LeetCode题。

## 📚 目录结构

- **topics/** - 核心知识点讲解
- **examples/** - 代码示例和实现
- **notes/** - 个人学习笔记
- **questions/** - 面试题整理
- **resources/** - 参考资料链接
- **data-structures/** - 数据结构实现（ADT、链表、栈、队列等）
- **algorithm-implementations/** - 算法实现（排序、搜索、动态规划等）
- **company-interviews/** - 各大公司面试题（阿里、字节、腾讯等）
- **problem-solutions/** - 算法问题解决方案
- **utilities/** - 工具类和辅助代码

## 🎯 学习目标

掌握常见算法类型和数据结构，熟练解决LeetCode中等难度以上的题目。

## 📖 主要内容

- 数据结构：数组、链表、栈、队列、树、图、并查集等
- 算法类型：排序、搜索、动态规划、贪心、回溯、分治等
- 时间复杂度分析和空间复杂度优化
- 位运算技巧
- 树和图的遍历算法

## 💡 重点难点

- 动态规划状态转移方程的推导
- 树和图的遍历算法（DFS、BFS）
- 复杂度的分析和优化
- 递归和迭代的转换
- 边界条件的处理
